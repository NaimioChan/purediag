# PureDiag

图表和流程图绘制解决方案

- 直接下载：[Releases](https://github.com/NaimioChan/purediag/releases/latest) 里的
  `PureDiag-16.0.2-setup.exe`
- 或用 git 克隆本仓库（需要 [Git LFS](https://git-lfs.com)，否则拿到的只是指针文件）

```
git lfs install
git clone https://github.com/NaimioChan/purediag.git
```

## 版本 16.0.2

| 项目 | 值 |
|---|---|
| 文件 | `PureDiag-16.0.2-setup.exe` |
| 大小 | 276,188,336 字节（约 263 MiB） |
| SHA-256 | `d31f684017743b0622ac17e8c2242b947d3f62cf9d0246b31f0e6eff69635f6d` |
| 对应程序版本 | 16.0.2 |

安装包用 Inno Setup 打包，内置简体中文安装向导。安装到 `Program Files`，
注册 `.eddx` / `.edx` / `.edxz` 三种文档关联，控制面板可正常卸载。

## 运行环境

- Windows 10 / 11，64 位
- 需要管理员权限安装
- 程序本身是 32 位，安装位置在 64 位 Program Files
