# PureDiag

某款国产制图软件桌面版的精简构建：去掉试用标识、推广入口、启动闪屏、登录与云功能，
界面上的品牌痕迹统一替换为 PureDiag。

**本仓库只发布安装包，不含任何源码。** 构建脚本、补丁定义与逆向笔记都不公开。

## 下载

- 直接下载：[Releases](../../releases/latest) 里的 `PureDiag-16.0.2-setup.exe`
- 或用 git 克隆本仓库（需要 [Git LFS](https://git-lfs.com)，否则拿到的只是指针文件）

```
git lfs install
git clone https://github.com/NaimioChan/purediag.git
```

## 精简了什么

- 标题栏的「（试用版）」后缀
- 右上角推广区：应用中心、消息、分享、发布
- 登录按钮、账号区按钮、会员购买按钮
- 启动加载闪屏
- 「文件」页：云文档、模板社区、个人云、右侧登录栏
- 整个「帮助」页签
- 「关于」对话框里的品牌横幅
- 程序文件属性里的公司名、产品名、文件描述、版权、原始文件名
- exe 图标、启动画面与安装向导图标换成 PureDiag 的 logo

功能面没有改动：绘图、模板库、公式、导入导出都按原样保留。

## 运行环境

- Windows 10 / 11，64 位
- 需要管理员权限安装
- 程序本身是 32 位，安装位置在 64 位 Program Files
